# Hotel, Restaurant & Lodge Management System

## Overview

A full-stack management system developed to streamline hotel, restaurant, and lodge operations through a centralized platform. The application helps manage room bookings, guest check-ins, restaurant orders, inventory, billing, housekeeping, and user management.

## Features

### Lodge Management

* Room availability and booking management
* Guest check-in and check-out
* Housekeeping management
* Room service management
* Amenities management
* Billing and payment tracking
* Night audit and reporting

### Restaurant Management

* Table management
* Menu and category management
* Order processing
* Inventory management
* Supplier and purchase tracking
* Customer management
* Reservation management
* Sales and reports

### User Management

* JWT-based authentication
* Role-based access control (Admin, Manager, Staff, Kitchen Staff)
* User activity logging
* Password management

## Technologies Used

### Frontend

* React.js
* Bootstrap
* Axios
* React Router

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* bcryptjs

## Installation

### Backend

```bash

```

### Frontend

```bash

```
